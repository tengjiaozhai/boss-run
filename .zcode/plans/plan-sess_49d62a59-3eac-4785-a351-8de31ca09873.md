# AI 匹配报告 UI 入口实施计划

## 结论

在设置页（`GeekAutoStartChatWithBoss/index.vue`）新增「AI 匹配」配置分区，暴露 `enableAiMatch` 开关和 `aiMatchThreshold` 阈值，完全复用现有「摸鱼模式」分区的实现模式（el-checkbox 开关 + el-input-number 参数 + 保存走 `save-config-file-from-ui` IPC 白名单）。

## 取舍说明

- **只暴露 2 个字段**：`enableAiMatch`（开关）+ `aiMatchThreshold`（0-100 整数，默认 85）。`aiMatchTimeout`（默认 30s 够用）和 `aiMatchFallbackStrategy`（默认 2=仅本地标记，安全值）不暴露，配置文件仍可直接改。
- **放设置页而非 MatchReport 报告页**：所有 `boss.json` 字段的编辑都集中在设置页表单，报告页是 KeepAlive 数据展示页。
- **控件用 el-checkbox**：跟随设置页现有布尔控件（isSageTimeEnabled）的写法，不用 el-switch。

## 改动清单（2 个文件，5 处）

### 文件 1：`packages/ui/src/renderer/src/page/MainLayout/GeekAutoStartChatWithBoss/index.vue`

1. **模板**：在 1657 行「活跃度」分区的 `</el-card>` 之后、`</el-form>` 之前，插入新的 `el-card class="config-section"`：
   - 标题「AI 匹配」+ 说明文字：本地筛选（薪资/城市/活跃度等）通过的岗位会交给 LLM 评估并生成匹配报告，分数低于阈值时仅本地标记为不合适；配置保存后需重新运行任务才生效（worker 启动时读取一次配置）。
   - `el-checkbox v-model="formContent.enableAiMatch"`「启用 AI 匹配评估」，`@change` 埋点 `ai_match_enable_changed`。
   - 阈值行 `el-input-number v-model="formContent.aiMatchThreshold"`：`:min="0" :max="100" :step="1" step-strictly :precision="0" :disabled="!formContent.enableAiMatch" controls-position="right"`，埋点 `ai_match_threshold_changed`；跟随摸鱼模式做关闭态文字变灰（`:style="{ color: formContent.enableAiMatch ? '' : '#aaa' }"`）。

2. **formContent 默认值**（1812 行摸鱼配置附近）加 `enableAiMatch: false, aiMatchThreshold: 85`。

3. **fetch 回填**（1964 行 isSageTimeEnabled 回填附近）加两个字段回填，`aiMatchThreshold` 做 NaN/越界兜底为 85（与 sageTimeOpTimes 回填同构）。

4. **formRules**（2078 行 sageTimePauseMinute 规则之后）加 `aiMatchThreshold` validator：开关关闭时跳过校验；值必须为 0-100 整数。

### 文件 2：`packages/ui/src/main/flow/OPEN_SETTING_WINDOW/ipc/index.ts`

在 161-169 行 isSageTimeEnabled/sageTime* 分支附近，按现有 `hasOwn` 白名单模式加两个分支：`enableAiMatch`、`aiMatchThreshold`。

### 不改的部分

- worker 端 `packages/geek-auto-start-chat-with-boss/index.mjs` 已消费这两个字段，无需改动。
- `default-config-file/boss.json` 已含全部 4 个 aiMatch 字段，无需改动。
- MatchReport.vue 报告页保持只读数据页。

## 验证

1. 在 `packages/ui` 下运行 `npm run typecheck`（node + web 两部分）。
2. 运行 `npm run lint` 确认无新错误。
3. `npm run dev` 启动应用，进入设置页确认：新分区正常渲染；改开关和阈值点「仅保存配置」后，`~/.geekgeekrun/config/boss.json` 中 `enableAiMatch`/`aiMatchThreshold` 更新；关闭开关时阈值输入框禁用且校验跳过。
